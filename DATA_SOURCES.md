## LUCAS

Source: Eurostat, LUCAS 2018 primary data, Estonia, file `EE_2018_20200213.CSV.csv`.

- Landing page: https://ec.europa.eu/eurostat/web/lucas/database/2018
- Official file identifier: `35a509fc-1b8d-8263-dd72-991457f4c008`.
- File link: https://ec.europa.eu/eurostat/documents/205002/8072634/EE_2018_20200213.CSV.csv/35a509fc-1b8d-8263-dd72-991457f4c008
- Reuse notice: https://ec.europa.eu/eurostat/help/copyright-notice

Eurostat permits reuse of statistical data with source acknowledgement, subject to individual notices and third-party exceptions. Modified data must be identified and accompanied by a statement that Eurostat is not responsible. This package uses the public primary records, not separately requested restricted grassland data or survey photographs.

Modifications: records were joined to WorldCover native pixels; binary woodland/tree indicators and projected coordinates were added. The 2,665 source records and their order are preserved. The derived data and analyses are the author's responsibility; Eurostat is not responsible for these modifications or their interpretation. A file URL is recorded rather than an invented dataset DOI.

## WorldCover

Zanaga et al. (2022), ESA WorldCover 10 m 2021 v200, Zenodo, https://doi.org/10.5281/zenodo.7254221.

Official licence and attribution guidance: https://esa-worldcover.org/en/data-access. The product is supplied under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.

The source is the numerical Map product for native tiles N57E021, N57E024 and N57E027. Derived values classify Map code 10 as tree cover at sampled sites. These are derived data, not an unmodified ESA product. The reference year is 2021; LUCAS reference labels concern 2018.

Credit: ESA WorldCover project 2021; Copernicus Sentinel data processed by the ESA WorldCover consortium. Any subsequent published map must also follow the product's map-layer attribution guidance.

## Local provenance and limits

`manifest.json` identifies packaged bytes. The research archive records source TIFF/CSV hashes and source-to-join checks. All saved sampling masks and populations remain unchanged. The package excludes source rasters, photos, canopy data, virtual environments and access credentials.

The author's research software uses BSD-3-Clause; repository destination and release approval remain pending. Data-source reuse terms do not grant a licence to unrelated code or to every third-party item that might later be added.


The additional S6.3 experiment uses simulated Gaussian fields and Bernoulli labels only. Its saved populations are synthetic, generated by the recorded seed/specification; no external dataset is used.
